# Design
App-managed LocalProbeManager owns one ProbeEngine and a bounded UUID reservation map. reserve is synchronous, only main webview allowed; max16 entries, unused reservations expire15s. run consumes once via started flag, uses RAII lease that cancels/removes on drop. cancel removes an unused reservation or signals an active run; missing IDs are idempotent. Window destruction cancels/removes its entries. No task/result polling or persistence. Requests use explicit host/kind/port; results reuse fixed core contract.
React local diagnostics component mounts only in existing network view, inside existing lazy DockerToolPanel. Shared AppSelect, global field/button/form/result classes and Lucide. Local operation controller pins each async reserve/run/cancel; cancellation before reserve response releases the late lease without starting; inactive/unmount ignores late callbacks and requests cleanup. Errors use fixed translated messages, never stringify exception/target. Run inputs disabled while busy; explicit cancel retries are allowed if IPC cancellation failed. No automatic probe on profile/focus change; scoped remount resets drafts.
Use Trellis before-dev/check and existing token/UI rules. ui-ux-pro-max unavailable (prior discovery); reuse shared controls instead of a new design system. GUI/theme acceptance remains MANUAL_REQUIRED.
