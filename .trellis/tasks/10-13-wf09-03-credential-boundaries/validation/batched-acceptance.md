# WF-09-03B 集中验收

维护者要求后续统一验收；以下均为 MANUAL_REQUIRED，Rust/前端测试不能代替真实 GUI/平台 provider。

| 编号 | 操作 | 预期 |
|---|---|---|
| B-01 | 创建密码/密钥口令含首尾空格的账号；保存、重启、连接 | 原字符保持，untouched 编辑不改秘密 |
| B-02 | 账号被保存连接引用时删除；取消删除弹窗 | 明确拒绝；取消不发 mutation；账号/秘密保留 |
| B-03 | 未引用账号删除；曾切换认证类型的账号删除 | 记录与当前/旧认证类型槽位移除；其它账号不受影响 |
| B-04 | 删除时锁定、provider/write failure、SQL failure、慢旧列表 | 锁后旧 handle 不读写秘密；失败不静默丢记录；旧列表不恢复已删账号 |
| B-05 | 元数据/快照/诊断与显式加密导出 | 普通结构化数据无秘密值；显式加密包仍可授权解密；锁定后不能导出秘密 |
| B-06 | 换密/锁定后继续原 SSH/Files/传输，并再次解锁 | 已有实例不关闭；新凭据访问遵循 Vault 状态；旧 handle 不恢复权限 |
| B-07 | Windows/macOS/Linux provider 与三个主题/两种语言 | 授权失败稳定、错误可定位、无明文兜底、界面状态可读 |

运行时错误回滚与进程崩溃恢复分别验收；本刀不声明跨文件 crash 原子或加密备份的安全擦除。记录环境/提交/证据，不记录真实密码、私钥或令牌。
