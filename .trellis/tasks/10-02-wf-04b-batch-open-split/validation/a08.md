## A08：批量连接

同一 `A08 Batch` 分组包含 `A08-existing`、`A08-success`、`A08-fail`、`A08-wait` 四个 SSH profile。成功项使用有效测试密钥，失败项使用错误用户名，等待项使用每次连接询问模式；批次前先打开 `A08-existing`。

| 验收项 | 结果 | 实测证据 |
| --- | --- | --- |
| 预览 | PASS | “连接全部…”先打开预览；显示名称、SSH、分组路径、交互认证标记与选择数 3/20；包含子组默认开启且可切换。 |
| 已打开默认跳过 | PASS | `A08-existing` 显示“已打开”且默认未勾选。 |
| 成功、失败、等待用户 | PASS | 同批 `A08-success` 成功，`A08-fail` 明确报告 SSH 认证失败，`A08-wait` 进入等待用户状态。 |
| 取消剩余 | PASS | 等待项的本批实例关闭并标为已取消；成功与失败结果保留。 |
| pre-existing isolation | PASS | 已有实例和成功项均保留；已有实例取消、重试后仍可执行命令，Shell PID 前后一致。 |
| failed-only retry | PASS | 仅失败项产生第二次尝试；成功项、取消项、已有实例未重放，服务端交互 Shell 数量保持不变。 |
| 同 profile 取消隔离 | PASS | 维护者补验：保留旧实例，批量创建同 profile 新实例，在新实例等待认证时取消剩余，旧实例保留。 |

20 项上限、最多 4 个未完成启动项、waiting-user 占槽、queued 取消与主动取消竞态由既有 model / executor / runtime 测试及 source gate 覆盖。真实 GUI 混合批次选择 3 项，不将其写成超过 4 项的并发压力实测。

## Split smoke

| 验收项 | 结果 | 实测证据 |
| --- | --- | --- |
| 2 pane / exact instance host | PASS | 从 `A08-success` 第一个实例创建 Split，同 profile 的第二个实例仍在 Split 外。 |
| 已打开实例选择 | PASS | picker 列出具体实例；选入 `A08-existing` 后，原终端输出和 Shell PID 保留。 |

| 横/纵与 4 pane 上限 | PASS | 实际操作向右、向下及四分屏；维护者确认四 pane 后不能继续增加。 |
| divider / focus | PASS | 维护者确认横、纵分隔线可拖动；依次点击终端输入，字符只进入当前 pane。 |
| host 关闭后重新绑定 | PASS | 维护者确认剩余至少两个有效 pane 时 Split 保留，host 转移到内部存活实例，不选取同 profile 的外部 sibling。 |
