# WF-09-01C 实例归属与代码收口

用户在当前 SSH 实例的 Files 上传或下载，切换焦点不改变任务目标；关闭实例先确认，只取消该实例的活动任务。

继续 `09-23-nexaterm-workflow-mainline`，依据 WS-M01、WS-F01/F05/F08/F09。沿用已批准 WF-09-01 规划及 PR #58，不改 WF-08/A15、PR #12/#54 或发布门禁。

## 验收
- W09-01C-01：新传输固定 `ownerInstanceId=ssh:tabId`，与连接 ID 和 Rust 句柄分离；上传、下载、重试及临时转保存保持该身份。
- W09-01C-02：同配置两实例相互隔离；关闭 owner 需确认，取消确认不变更任务，确认期间已完成任务不再取消；旧无 owner 行只在最后一个连接实例关闭时取消。
- W09-01C-03：选择文件、读取本地 metadata、批量下载期间固定原目标；owner 已关闭时不再创建或重试传输。
- W09-01C-04：本地列表迟到响应不覆盖新导航；首次选择失败可见，隐藏/卸载期间不接受迟到响应。
- W09-01C-05：远程拖入本地目录使用原远程实例与所选本地目标，复用冲突与队列；非法拖放不触发 I/O。
- W09-01C-06：暂停队列只暂停新任务调度，恢复按 FIFO/限额继续；在途任务继续且可取消，不宣称字节级断点续传。
- W09-01C-07：自动化门禁与 CI 留证；真实桌面/SFTP 清单保持 MANUAL_REQUIRED，不伪造收口。

字节级暂停/断点续传、原生 Explorer/Finder 拖出不属于当前规划验收；不得通过改 A15 消除环境限制。
