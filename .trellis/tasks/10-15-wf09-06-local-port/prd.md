# WF-09-06D 本地端口冲突诊断
用户流程：Tools → Network 选择本地端口检查，明确执行后查看当前 IPv4 回环端口能否绑定。
验收：WF-09-06 LP01–LP04；A15（i18n 回归，不代表发布验收）；引用 WORKFLOW_SPEC WS-E06。沿用现有诊断表单与生命周期，不调整工作区布局。
- 只检查 127.0.0.1 上一个明确的 TCP 端口；区分可用、占用、权限拒绝、其他失败。
- 明示瞬时结果不保留端口、不覆盖其他地址/IPv6；不枚举进程或扫描端口。
- 固定范围、共享并发/截止时间/取消与无敏感数据契约；所有启动来自明确操作。
- 自动检查保留，真实三平台 GUI/native/theme 验收统一后续进行。
