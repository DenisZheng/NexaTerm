# Design
Reuse ProbeKind and local probe reservation IPC with local_port. Backend rejects any host except literal127.0.0.1 and port0, then binds a numeric SocketAddr without DNS. Use TcpSocket new_v4/bind (no listen/accept) and drop immediately. This avoids accepting connections just to test a bind. Distinguish AddrInUse, PermissionDenied and other bind errors with fixed reason codes. Keep existing four-operation/five-second cancellation boundary. No saved input/result or raw errors. UI shows fixed loopback scope and only port input; DNS/TCP retain their target input. Result kind pins scope after selector changes. Existing shared AppSelect/token styles; ui-ux-pro-max unavailable as already recorded, use repository components. No new dependencies.
