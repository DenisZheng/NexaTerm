# WF-09-02B：远程编辑另存为

用户在已读取的远程 UTF-8 编辑器选择另存为，输入同目录新文件名，成功后编辑器指向新文件；原文件不变，后续输入仍保留为未保存修改。

继续 09-23 workflow mainline 与已批准 WF-09-02 规划，引用 WS-F01/F05/F08/F09。沿用 PR #59 的分支与现有工具栏/命名弹窗，不改布局或持久化归属。真实 GUI/SFTP 验收按维护者指示后续统一进行，不自动合并。

## 验收
- W09-02B-01：按钮与 Ctrl/Cmd+Shift+S 打开命名弹窗；已验证的干净/修改文本均可另存，loading/缺 metadata/在途 I/O 不可重入。
- W09-02B-02：取消或非法文件名不写远端；原路径、已打开目标路径拒绝保存，提供可重试错误。
- W09-02B-03：内容通过 stdin 写入同目录私有临时文件，再用精确目标的原子 create-only 硬链接发布；已有文件/目录/符号链接（含竞争创建）不被覆盖，临时文件清理。缺少 link 或硬链接支持明确失败。
- W09-02B-04：成功迁移源编辑器的 id/path/name/metadata，savedContent 只记录本次 payload，保存期间新增输入保持 dirty；原文件不被修改，刷新目标目录。
- W09-02B-05：失败保留原编辑器与缓冲区、可换名重试；关闭/重开、卸载、改名使旧 token 失效，迟到回调不得迁移新标签或清除新弹窗。
- W09-02B-06：前后端契约、实际 shell 安全行为和控制器/状态测试通过，类型/构建/source/i18n 门禁通过；GUI/SFTP 为 MANUAL_REQUIRED。

本切片只支持同目录新文件名，不提供另存覆盖；普通保存继续使用既有 mtime/size 冲突确认。
