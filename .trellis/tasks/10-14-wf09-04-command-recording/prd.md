# WF-09-04B：显式命令录制与敏感占位

沿 09-23 主线、已批准 WF-09-04 规划和 PR #61 @ 98cac2d（CI #587 全部执行检查 SUCCESS）继续。用户明确选择一个 MultiExec 会话作为录制源，主动开始录制，通过已有 Command Sender 等显式发送入口发送完整命令，停止后编辑录制草稿并按 A 切片预览/确认重放。

引用 WS-X03/04/05/07/08、WS-F08。仅订阅显式命令发送成功，不采集原始 xterm 按键、密码提示、TUI 或输出。已知敏感模式启发式不能证明所有命令无秘密，必须在重放前人工复核。

## 验收
- M04B-01：录制默认关闭，必须明确选择一个有效源的 key/session 并开始；focus 不换源，断线/重连停止且不续录。
- M04B-02：仅录入对该源成功投递且 appendEnter=true 的命令；未选源的发送、失败、仅发送不带回车不构造有效步骤。录制不自动广播，不捕捉原始按键。
- M04B-03：发送开始时先过滤，已知密码/令牌/认证 URL/认证头/敏感参数和可能进入认证提示的命令产生空文本 masked 占位并立即暂停接收；不保留原值，不将已知敏感命令写自动历史。
- M04B-04：并发完成按提交顺序生成草稿；停止/重新开始后迟到成功不入新录制；20 步、16KiB/64KiB、每步 60s/总 300s 预算，超限明确停止而不静默改变延时。
- M04B-05：停止后编辑/删除占位再预览；未补填占位不可重放。每次仍明确预览目标，不采用录制源自动广播。
- M04B-06：关闭所属 MultiExec/卸载/重启丢弃内存草稿及 pending，无 history/snippet/snapshot/export/log 持久化；普通手动宏原样保持。
- M04B-07：实际模型、UI 与原 Sender handler 回归测试；类型/build/source/scripts 通过；English/简体与现有 token/Radix/按需边界。真实 GUI/协议/三主题按维护者要求 MANUAL_REQUIRED。

本刀不持久化/导入导出宏，不自动录制 shell 输入；这些独立于录制安全闭环。PR #12/#54/A15 独立，不自动合并。
