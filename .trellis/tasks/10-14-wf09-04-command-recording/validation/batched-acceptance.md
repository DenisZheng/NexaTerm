# WF-09-04B 集中验收

维护者要求后续统一执行；本表全部 MANUAL_REQUIRED。记录提交/系统/真实会话和证据，不记录真实秘密。

| 项目 | 操作与预期 |
| --- | --- |
| 默认与开始 | MultiExec 勾选实例，录制源默认未选；取消不录制，选择后开始不自动发送命令 |
| 显式命令 | 向 A/B 发送并回车，仅录入所选源成功投递的命令；命令原字符与提交间隔保持 |
| 源失效 | 断开/关闭/重连源，录制停止；focus 或新 session 不接替；已确认草稿可编辑 |
| 敏感命令 | 合成 TOKEN/密码参数/认证头/URL 与认证提示命令触发暂停；草稿仅空占位，后续认证回答不进入录制和此源自动历史 |
| 可选终端历史 | 开启已有 terminal history，对隐私暂停源输入合成回答；Native 输入照常送达，缓冲/迟到回调不写历史 |
| 编辑重放 | 停止并编辑，未补填占位不能预览；补填/删除后重新确认命令和目标再重放 |
| 失败与并发 | 源写入失败、其他接收者慢、乱序完成、停止/换源/清空后的迟到成功；只保留已确认源步骤 |
| 预算 | 20 步、16/64 KiB、60/300 秒；超限停止，不静默缩短延时或截断命令 |
| 清理 | 丢弃录制、关闭编辑器、隐藏 MultiExec、关闭窗口/重启；没有宏草稿持久化或自恢复 |
| 主题语言平台 | English/简体、Light/Dark/system-dark、长源名称和键盘操作；三平台真实 SSH/Local/已支持 Serial/Telnet 分别验收 |

已知模式为保守启发式，未知敏感值仍须人工检查；本刀没有原始按键自动录制、持久化或导入导出。全 WF-09-04 尚未最终验收。
