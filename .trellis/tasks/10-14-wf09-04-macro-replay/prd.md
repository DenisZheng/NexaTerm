# WF-09-04A：预览后宏重放

沿 09-23 主线和已批准 PR #53 的 WF-09-04 规划实施第一切片。用户明确勾选 MultiExec 实例，编辑宏步骤和每步发送前延时，预览全部命令与固定目标后确认重放，可取消后续写入。

引用 WS-X03/04/05/06/07/08、WS-F08。基线 PR #60 @ 542edbd，CI #586 三平台 Rust、Frontend、Security、License、fixtures 已通过；PR #12/#54/A15 独立。

## 验收
- M04A-01：既有 MultiExec 工具栏提供按需加载入口；不默认选中目标；打开宏停止 live 并收起 Command Sender。
- M04A-02：可增删编辑最多 20 步，每步发送前延时 0–60000ms，总延时不超过 300000ms；命令原样展示并追加 Enter；单条 16KiB、合计 64KiB，拒绝空白和隐藏控制字符。
- M04A-03：预览冻结命令及显式选择目标的 key/session 身份（最多 20 个）；确认之前无写入；切换焦点不改变目标，重连不接替旧 session。
- M04A-04：逐步逐目标通过既有 typed terminalWrite 输入通道发送；任何目标失效/写入失败/超时停止剩余重放，不自动重试。结果只表示写入终端。
- M04A-05：取消/关闭/卸载阻止后续写入并清除等待定时器；已发出的 native 写入无法撤回，至多等待 30 秒后标记未知结果的超时。重复确认不重复发送。
- M04A-06：草稿、session 身份、命令与错误载荷不写日志、历史、snapshot/export 或持久化；只有用户主动编辑内容进入内存草稿。
- M04A-07：English/zh-CN 文案、现有 Radix/全局 token 风格；实际自动化覆盖取消、失败、断线、重连、重复操作及 cleanup。真实 GUI/provider 验收为 MANUAL_REQUIRED。

本刀不包含原始按键录制、宏持久化或导入导出；下一切片另行处理保守录制和敏感输入遮蔽。完整 WF-09-04 未结束。
