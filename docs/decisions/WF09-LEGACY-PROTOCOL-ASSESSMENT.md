**原评估决定（历史）：本轮完成评估，原生 Rlogin / Rsh provider 暂缓（DEFER）。** 不在 UI、连接 schema 或 capabilities 中宣称已支持。已交付的 SSH/Telnet 行为不变。不增加提权 helper、外部程序自动执行或静默回退。该旧排期已由后续实现计划替代；靶机/profile 与互通证据在对应阶段建立，不作为所有开发工作的先决条件。这是原评估时证据下的工程决定，不表示用户不存在遗留需求。

## 需求证据与方案取舍

原评估时授权是完成 WF-09 评估，尚无指定 Rlogin/Rsh 服务端、版本、网络环境或只能使用这些协议的具体任务。现有 SSH shell/exec 已承载交互与命令执行，但不能据此认定所有遗留系统可迁移。可选方案：继续只提供已有协议（原评估选择，证据门槛明确）；提供外部客户端启动器（仍需程序来源、安装、参数、进程归属和许可评审，不能称为原生支持）；原生 provider（需要完整协议、平台权限与真实互通成本，原评估时不具备验证条件）。

## 必须区分的协议契约

| 项目 | Rlogin | Rsh |
|---|---|---|
| 目标语义 | 远程交互终端；RFC1282 描述 TCP513、NUL 分隔身份与终端信息、流控和窗口尺寸 | 远程命令执行；历史 OpenBSD rshd 描述主连接及 stderr/信号用次连接 |
| 认证边界 | 原协议包含信任主机机制；不能声称具有 SSH Host Key 认证或加密 | 历史实现依赖可信主机与客户端源端口512–1023；不能以普通高端口 TCP 成功替代 |
| 独立实现工作 | TCP urgent/OOB、流控、终端尺寸和关闭语义；不是套用 Telnet 编解码 | 次连接来源校验、取消/信号、stdout/stderr 生命周期与半关闭；不是打开一个交互 PTY |
| 数据边界 | 用户身份、终端输入、口令提示均不得进入诊断/快照/录制默认数据 | 命令、用户名、输出可能敏感；不得拼接 shell 参数或默认加入宏/历史/导出 |

RFC1282 是对既有实现的 Informational 记录。OpenBSD 5.3 手册是历史协议资料，不能作为当前 OpenBSD 默认安装或可用性的证明。扩展认证/加密变体必须另外定义，不可把一种变体的安全性质套用到全部服务器。

## 平台与可复核证据

本次 Linux6.18.44 x86_64/glibc2.39 环境 `shutil.which('rlogin')`、`shutil.which('rsh')`、`shutil.which('docker')` 均为 None；无真实服务端。Windows/macOS 本机及服务端不可用。所有三平台互通、特权端口策略和 GUI 行为均为 **MANUAL_REQUIRED**；未尝试提权、启用 rshd、改 hosts.equiv/.rhosts 或连接公网目标。该文档不包含协议运行成功证据，CI 也不能替代它。

## 原评估提出的门槛（历史；现按新计划分阶段验证）

- 定义一个可复现的业务需求、指定服务端/协议变体及隔离靶场。记录每个平台的客户端/服务端版本、服务配置与许可来源；未审计的软件不复制或打包。
- 在现有 provider/能力模型下独立注册；默认关闭，每次创建不安全连接明确 opt-in 与告知，自动恢复不能静默建立连接。无原生实现的平台显示真实不可用原因。
- 不为兼容源端口规则自动提权、降低系统策略或安装 helper；若现有权限不能满足，明确 unavailable。避免自动使用 SSH 保存凭据或承诺 Host Key 保障。
- 生命周期先定合同：单次连接固定实例/操作身份、总截止时间、有界缓冲与并发；失败释放所有连接，取消/关闭收回主流/次流和 reader；重试创建新句柄，旧事件不能写入新实例。Rsh 次连接必须绑定允许的地址并验证目标归属，不能接受任意回连。
- 必须实测：认证拒绝、源端口拒绝、握手中取消、超时、网络断开、Rlogin resize/OOB/流控、Rsh stderr/信号/次连接拒绝、同时两实例、重试与窗口销毁。检查密码/命令/运行句柄未进入日志、快照、导出或宏默认录制。

## 一手来源（2026-10-16 查阅）

- [RFC1282: BSD Rlogin](https://www.rfc-editor.org/rfc/rfc1282.html)：握手、终端控制、关闭与信任模型。
- [OpenBSD 5.3 rshd(8)，历史手册](https://man.openbsd.org/OpenBSD-5.3/rshd.8)：源端口、次连接、身份和命令协议，明确建议使用 SSH。
- 仓库 `src/features/connections/connectionTypes.ts`：当前支持的保存连接协议；本评估未增加新协议枚举或改变凭据/会话 schema。
